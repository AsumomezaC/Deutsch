Zeit -> tiempo

Genau -> ahora
jetzt -> ahora

jede/r -> cada 'x' tiempo/evento
noch einmal -> una vez más

Geburtsdatum -> fecha de nacimiento

heute -> hoy
gestern -> ayer

Wahn -> a qué hora?

letzten X -> El 'X' pasado, siendo 'X' la [[Fechas - Alemán|fecha]] a la que se hace referencia (ej. letzten Freitag -> el viernes pasado)

> [!important] la forma de **letzten** depende del sujeto que sigue:
> - Masculino -> letzten
> - Neutro -> letztes
> - Femenino -> letzte

## Horas
Wie spät ist es? -> q hora es?
	Wie viel Uhr ist es?
Viertel -> cuarto -única con mayúsculas-
halb -> media
kurz vor 'x' -> poquito antes de las 'x'
kurz nach 'x' -> poquito después de las 'x'

vor -> antes
nach -> después
>'um' se usa en las horas
### Estructura
De forma coloquial se dice primero lo que falta y luego la hora
**E.j.**
7:15 -> Viertel nach sieben
4:30 -> halb fünf
4:35 -> fünf nach halb fünf, fünfundzwanzig vor fünf
### Rangos
Es ist...

| minutos | forma             |
| ------- | ----------------- |
| 00-20   | 'x' nach ...      |
| 20-30   | 'x' vor halb ...  |
| 30-40   | 'x' nach halb ... |
| 40-00   | 'x' vor ...       |
>Los 'Viertel' solo se usan en horas exactas

> [!important] Manera formal
> En la manera formal se usan el formato de 24 horas -yupiiii-. Y se dice Es ist 'x' Uhr 'm' Minuten.
