### 2. Las Decenas (13-19)
**Patrón:**
> Número + **-zehn** (diez)
> Ejemplo: vier (4) + zehn (10) = vier**zehn** (14)

| Número | Alemán   | Pronunciación (approx.) | Excepción / Nota                         |
| ------ | -------- | ----------------------- | ---------------------------------------- |
| 13     | dreizehn | /drái-tséen/            |                                          |
| 14     | vierzehn | /fír-tséen/             |                                          |
| 15     | fünfzehn | /fünf-tséen/            |                                          |
| 16     | sechzehn | /zéj-tséen/             | ❗ **Sechs** pierde la "s": **sech**zehn. |
| 17     | siebzehn | /síep-tséen/            | ❗ **Sieben** pierde "en": **sieb**zehn.  |

### 3. Las Decenas (20, 30, 40... 90)
**Patrón:**
> Número + **-zig** (como el sufijo "-enta" en español)
> Ejemplo: vier (4) + zig = vier**zig** (40)

| Número | Alemán  | Pronunciación (approx.) | Excepción / Nota                                                   |
| ------ | ------- | ----------------------- | ------------------------------------------------------------------ |
| 20     | zwanzig | /tsván-tsij/            | ❗ **Zwei** se convierte en **zwan**zig.                            |
| 30     | dreißig | /drái-sij/              | ❗ **Drei** + **ßig** (no "zwei**zig**"). La "ß" es una "s" fuerte. |
| 40     | vierzig | /fír-tsij/              |                                                                    |
| 50     | fünfzig | /fünf-tsij/             |                                                                    |
| 60     | sechzig | /zéj-tsij/              | ❗ **Sechs** pierde la "s": **sech**zig.                            |
| 70     | siebzig | /síep-tsij/             | ❗ **Sieben** pierde "en": **sieb**zig.                             |
| 80     | achtzig | /ajt-tsij/              |                                                                    |
| 90     | neunzig | /nóin-tsij/             |                                                                    |

### 4. Los Números Compuestos (21, 22, 33, 47, 68, 99, etc.)
**¡Este es el patrón más importante y diferente del español!**

**Estructura en Alemán:**
> **Unidades** + **und** (y) + **Decena**
> *Ejemplo en español: "uno y veinte" en lugar de "veintiuno".*

**Fórmula: 'Unidad' und 'Decena'**

| Número | Alemán          | Pronunciación (approx.) | Análisis |
|--------|-----------------|--------------------------|----------|
| 21     | **ein**und**zwanzig** | /áin-unt-tsván-tsij/ | 1 (ein) y (und) 20 (zwanzig) |
| 22     | **zwei**und**zwanzig** | /tsvái-unt-tsván-tsij/ | 2 (zwei) y (und) 20 (zwanzig) |
| 33     | **drei**und**dreißig** | /drái-unt-drái-sij/ | 3 (drei) y (und) 30 (dreißig) |
| 47     | **sieben**und**vierzig** | /sí-ben-unt-fír-tsij/ | 7 (sieben) y (und) 40 (vierzig) |
| 58     | **acht**und**fünfzig** | /ajt-unt-fünf-tsij/ | 8 (acht) y (und) 50 (fünfzig) |
| 69     | **neun**und**sechzig** | /nóin-unt-zéj-tsij/ | 9 (neun) y (und) 60 (sechzig) |
| 99     | **neun**und**neunzig** | /nóin-unt-nóin-tsij/ | 9 (neun) y (und) 90 (neunzig) |

**Nota importante:** Para el 21, se dice `einundzwanzig`, no `einsundzwanzig`. La `-s` de `eins` desaparece.

### 6. Números Complicados (101, 125, 234, 567, 999)
**Aquí combinamos todo. El orden es siempre: 'Centenas' + 'Unidades y Decenas'**

**Regla:** Primero se dicen las centenas, y luego el número restante (del 1 al 99) se forma con las reglas que ya conoces.

| Número | Alemán                 | Análisis Paso a Paso |
|--------|------------------------|----------------------|
| 101    | **hundert**eins        | 100 (hundert) + 1 (eins) |
| 111    | **hundert**elf         | 100 (hundert) + 11 (elf) |
| 125    | **hundert**fünfundzwanzig | 100 (hundert) + 25 (fünf**und**zwanzig) |
| 234    | **zweihundert**vierunddreißig | 200 (zweihundert) + 34 (vier**und**dreißig) |
| 384    | **dreihundert**vierundachtzig | 300 (dreihundert) + 84 (vier**und**achtzig) |
| 567    | **fünfhundert**siebenundsechzig | 500 (fünfhundert) + 67 (sieben**und**sechzig) |
| 999    | **neunhundert**neunundneunzig | 900 (neunhundert) + 99 (neun**und**neunzig) |

---

### Resumen de Patrones Clave

1.  **Orden inverso:** Para números del 21 al 99, la estructura es **"unidad Y decena"** (einundzwanzig = 1 y 20).
2.  **Excepciones en la formación:**
    *   **16, 17:** sechzehn, siebzehn (pierden letras).
    *   **20, 30:** zwanzig, dreißig (no siguen el patrón -zig perfectamente).
    *   **60, 70:** sechzig, siebzig (pierden letras).
3.  **Centenas y miles:** Son mucho más lógicos. Se dice la centena y luego el número restante pegado.

### Palabras Clave para Recordar
*   **und:** La palabra "y". Es el conector que cambia el orden.
*   **-zehn:** El sufijo para los números 13-19.
*   **-zig:** El sufijo para las decenas (20, 30, etc.).
*   **hundert:** Cien.
*   **tausend:** Mil.
