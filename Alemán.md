## Pronombres
Existen tres géneros: masculino (der), femenino (dis) y neutro(das).
>Plural: die (los)


> [!tip] El género depende de la última parte de la palabra (útil para [[Vocabulario combinado-alemán]])
> - Todas las palabras terminadas en -ung son femeninas
### ich
ich (en [[Alemania del sur]] se pronuncia 'igg') -> yo
### du
du -> tú
>Generalmente es cuando te refieres con el nombre
### Sie
Sie -> usted
>Usualmente se le llama a la persona con su apellido, ej Frau Wachter
### er
er -> él
### sie
sie -> ella / ellos
### man
man -> impersonal (se conjuga como [[#er]], [[#sie]], [[#es]])
>Similar al 'oni' en [[Esperanto]], o 'ce' en [[Francés]] (pe: se habla, se come, se corre)
### wir
wir -> nosotros
### es
es -> eso
### ihr
ihr -> vosotros -se conjuga de manera distinta-

### Género
> [!tip] Formato
> Género -> artículo / pronombre

Todos los objetos tendrán un género:
#### Nominativ (Nominativo)
>Útil siempre que hablemos del sujeto.
- Masculino -> der / [[#er]] / ein / kein
>La mayoría que terminan en '-er', '-or', '-ling', '-ismus'
- Femenino -> die / [[#sie]] / eine / keine
>La mayoría que terminan en '-ung', '-keit', '-heit', '-schaft', '-tät', '-ur', '-ion', '-ei', '-e' (es la de más excepciones)
- Neutro -> das / [[#es]] / ein / kein
>La mayoría que terminan en '-chen', '-lein', '-um', '-ment', palabras extranjeras, acciones vueltas sustantivos
- Plural -> die / *no sé* / *se omite* / keine
#### Akkusativ (acusativo)
>Cuando un sujeto ejerce acción sobre otro sujeto, el segundo sujeto se declina.
- Masculino -> den / einen / keinen
- Femenino -> die / eine / keine
- Neutro -> das / ein / kein
- Plural -> die / *se omite* / keine
